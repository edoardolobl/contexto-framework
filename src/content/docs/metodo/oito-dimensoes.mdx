# As oito dimensões do conhecimento explícito

Estas perguntas funcionam como um roteiro, não como burocracia. Faça-as ao especialista do assunto e documente respostas verificáveis.

| Dimensão | Pergunta |
|---|---|
| Significado | O que este termo significa nesta organização? |
| Contexto | Quando se aplica e quando não se aplica? |
| Objetivo | Para que este conhecimento é utilizado? |
| Regras | Quais condições e restrições definem o comportamento correto? |
| Exceções | O que acontece fora do fluxo esperado? |
| Responsabilidade | Quem executa, decide, aprova e esclarece dúvidas? |
| Evidência | Qual é a fonte oficial e como se verifica a informação? |
| Validade | Desde quando a informação é verdadeira e quem a revisa? |

## Como aplicar

1. Escolha uma definição, processo ou decisão que sua equipe domina.
2. Responda às dimensões relevantes; não invente respostas para preencher campos.
3. Identifique as lacunas e registre quem pode resolvê-las.
4. Traga casos reais, contraexemplos e exceções.
5. Submeta o registro ao proprietário do conhecimento.
6. Marque como aprovado apenas o que foi efetivamente validado.

Um template pode ajudar, mas a qualidade depende do entendimento e da validação do conteúdo.
